## Eat Sleep Poop
"_EatSleepPoo_" on the app store

I made this because I wanted the absolute simplest app for tracking basic activity for my newborn daughter. I threw this together in a couple days after she was born, and it has turned out to be helpful for us.

```
cd ios && pod install
yarn ios
```
